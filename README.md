Чат с документами — RAG MVP
Небольшой веб-интерфейс на Streamlit: загружает PDF, DOCX, TXT и Markdown, разбивает текст на фрагменты, строит для них векторный индекс и отвечает на вопросы только с опорой на найденный контекст.

Запуск на Windows
cd "C:\Users\zeeff\Documents\Codex\2026-09-06\new-chat\outputs\document-rag-chat"
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:OPENAI_API_KEY = "ваш_ключ"
streamlit run app.py
Либо введите ключ прямо в боковой панели после запуска. Он не записывается в файлы и живёт только в памяти текущей сессии.

Как устроено
Из PDF сохраняется номер страницы; из DOCX/TXT/MD — документ целиком.
Текст делится на перекрывающиеся фрагменты по ~1200 символов.
Фрагменты и вопрос превращаются в эмбеддинги text-embedding-3-small.
По косинусной близости выбираются 5 подходящих фрагментов.
Вопрос и эти фрагменты отправляются в Responses API. В ответе модель обязана приводить ссылки вида [1]; ниже раскрывается сам набор использованных фрагментов.
По умолчанию стоит gpt-5.4-mini; поле модели можно поменять на доступную в вашем API-модели. Модель ответов и эмбеддинги требуют оплачиваемого OpenAI API.

Ограничения MVP
Индекс и переписка не переживают перезапуск приложения.
Сканированные PDF без текстового слоя потребуют OCR.
В продакшене стоит вынести ключ на сервер, добавить авторизацию, постоянное векторное хранилище, фоновые задачи, лимиты файлов и тесты качества ответов.
Пример вопроса
После загрузки договора: Какие сроки оплаты указаны в документе?
